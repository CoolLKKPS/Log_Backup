# Log_Backup
This mod provides a simple way for user to point out issues:<br>
1. Press key to print some debug logs that may helpful for some people;<br>
2. Log files will be backed up each time when the game just launches or closing, and only when the game actually crashed or the key was pressed in-game;<br>
3. Log files will be saved into the `BepInEx/Log_Backup` folder;<br>
4. You can change keybind via `LethalCompany_InputUtils`.<br>
